# Tracewick Laravel

Laravel package for [Tracewick](https://github.com/tracewick/tracewick), a PHP sampling profiler.
This repository contains the package and its Laravel service provider. HTTP profiling is planned
for the next development milestone.

| Laravel | PHP |
| --- | --- |
| 12 | 8.2–8.5 |
| 13 | 8.3–8.5 |

During development, applications using the Tracewick release candidate can explicitly require
core version 1.0.0-rc.1 and keep their current Composer stability setting.

See [CONTRIBUTING.md](CONTRIBUTING.md) for development and checks.
